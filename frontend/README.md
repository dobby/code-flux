# Code Flux Frontend

Phase 0 frontend shell for Code Flux using Vue 3, TypeScript, and Vite.

## Scripts

- `npm run dev` starts local development server
- `npm run build` runs type-check and production build
- `npm run preview` serves built output locally

## Notes

- Vue Router is configured with a placeholder dashboard route at `/`.
- Vite development server proxies backend requests from `/api` to `http://localhost:8086`.
